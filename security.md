**Will this work with other mods?**  
Yes. The collection is compatible with most other mods. Install additional mods after the base collection.

**Why does the game keep crashing?**  
Make sure you installed the 4GB Patcher and NVAC. Run the game through `nvse_loader.exe`, not the default launcher.

**How do I uninstall?**  
Run the installer again and select "Uninstall" or delete the mod files manually.

**Can I use Vortex or Mod Organizer 2?**  
Yes. You can import the mod files into MO2 or Vortex manually. The installer creates a standard mod structure.

**Will ENB affect performance?**  
The included ENB preset is performance-friendly. Disable it if you experience FPS drops.

**Does this include New Vegas Script Extender (NVSE)?**  
Yes. NVSE is included and required for many mods.

**Is this save-game compatible?**  
Yes for most mods. Some gameplay mods (JSawyer, Economy) require a new game for best results.
